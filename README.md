# LOL Team Schedule Tracker

Tiện ích Chrome theo dõi lịch thi đấu **Liên Minh Huyền Thoại** (LoL) — đội tuyển & giải đấu, cập nhật realtime từ [PandaScore API](https://developers.pandascore.co).

## Tính năng

- Theo dõi nhiều đội tuyển / giải đấu
- Xem lịch thi đấu: đã diễn ra · đang live · sắp tới
- Bảng xếp hạng giải đấu
- Badge trên icon hiển thị giờ trận gần nhất
- Cache API 1 giờ (giảm rate-limit)
- Kéo-thả sắp xếp thứ tự đội / giải
- Highlight trận đấu trong ngày
- Cấu hình API Key riêng (Options)
